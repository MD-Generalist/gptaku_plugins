# gptaku plugins 랜딩 설계안 (2026-09-28)

근거: `reference-survey.md`(Aside로 10곳 실방문) + inspo 다크 개발자 도구 24곳 실측(다크 79%, 그로테스크 산세리프 83%).

## 1. 방향 한 줄

"주장 대신 재생 가능한 증거." 레퍼런스들의 공통 문법(짧은 헤드라인, 히어로 바로 밑 살아있는 제품, CTA 2개 이하, 포인트 컬러 하나)을 따르고, 차별점 세 가지를 얹는다.

1. **에이전트용 입구**(firecrawl): 설치 박스에 `사람이 설치` / `Claude에게 맡기기` 탭을 둔다. 두 번째 탭은 Claude Code에 붙여넣는 한 문단이다.
2. **재현 가능한 증거**(bun + herdr): 모든 수치 옆에 측정 날짜와 `재현` 명령을 붙인다. 다른 도구가 나은 경우까지 적은 솔직한 비교표를 둔다.
3. **담아서 한 번에 설치**(Raycast 카드 메타 + Smithery 장바구니): 허브 카드를 체크하면 하단 바가 설치 명령을 한 줄로 합쳐 준다.

## 3. 허브 `/`

1. **Nav**: 로고, 플러그인, 데모, GitHub(스타 수 실측 표기).
2. **Hero**(첫 화면 안에서 끝남): 헤드라인 "Claude Code가 **멈추는 곳**에서, 계속 가게." 서브카피 1줄. 설치 박스(탭 2개와 복사 버튼). 그 아래 숫자 한 줄: 플러그인 18종 · MIT · 대표 플러그인 스타 수.
3. **먼저 보세요**: 데모 영상 카드 2장(insane-search, insane-research). 카드마다 실측 한 줄 캡션을 단다.
4. **카탈로그**: 카테고리 칩(전체 / 웹·리서치 / 개발 / 기획 / 생산성 / 콘텐츠)과 전체 그리드를 한 화면에 둔다. 18개라 페이지네이션은 두지 않는다.
   - 카드: 아이콘, 이름, 한 줄 기능, 슬래시 커맨드, 버전, `담기` 체크.
   - 하단 고정 바: "3개 담음 · 설치 명령 복사".
5. **솔직한 안내**: 비공식 커뮤니티 플러그인이라는 점, 무엇을 로컬에서 실행하는지.
6. **마감**: 설치 박스 반복, 푸터.

## 4. insane-search `/insane-search/`

1. **Hero**: "WebFetch가 **403**에서 멈출 때, insane-search는 계속 간다." 설치 탭 2개. 보조 링크 "지원 플랫폼 전체".
2. **데모 영상**(풀폭): 같은 쿠팡 URL을 왼쪽 WebFetch는 403, 오른쪽 엔진은 52번째 시도에서 상품표 회수. 캡션에 실행 날짜.
3. **오늘 돌려본 결과**: 쿠팡·레딧·네이버·X 4행. 열은 일반 요청 / insane-search / 뚫은 경로 / 시간 / `재현`(복사되는 engine 명령).
4. **어떻게 뚫나**: 01 공식 경로 → 02 사람처럼 보이기 → 03 진짜 브라우저. 계단형 3단.
5. **솔직한 비교**: WebFetch / 호스팅 크롤러 / insane-search. 대량 크롤링은 호스팅 크롤러가 낫다고 적는다.
6. **마감**: 설치 반복.

## 5. insane-research `/insane-research/`

1. **Hero**: "그럴듯한 리포트 말고, **검증을 통과한 문장만**." 설치 탭 2개. 숫자 한 줄(에이전트 8 · 소스 109 · 검증 42/32/0).
2. **데모 영상**: 에이전트 → 소스 A–E 등급 → 검증 게이트.
3. **검증 장부 시각화**: 주장 74건이 검증 42(본문) / 미확정 32(부록) / 반박 0으로 갈라지는 흐름도. 실제로 부록으로 밀린 주장 1건을 사유("독립 출처 1개 < 2")와 함께 보여준다.
4. **샘플 리포트**: 실제 산출물 카드와 원문 페이지 링크.
5. **솔직한 비교**: 웹 딥리서치 / insane-research.
6. **마감**: 설치 반복.

## 6. 현재 `site/` 구현과의 차이

이미 있는 것: 다크 토큰, 데모 영상 2편, 결과표, 비교표, 샘플 리포트.
추가할 것: 설치 박스의 에이전트 탭, 결과표의 `재현` 열, 허브의 카테고리 칩과 담기 바, research의 검증 장부 흐름도. 그라디언트는 강조 단어 하나로 줄이고, 플러그인 액센트를 페이지별로 하나로 고정한다.
