Claude Code plugin · No API key

403 is not
an answer.

When WebFetch hits a 403, a WAF or a CAPTCHA on a public page, insane-search switches routes (public APIs and feeds, then browser TLS fingerprints, then a real Chrome) until the content comes back. No API key needed. At logins and paywalls it stops and tells you so.

/plugin marketplace add https://github.com/fivetaku/gptaku_plugins.git
/plugin install insane-search@gptaku-plugins
Run `claude plugin marketplace add fivetaku/gptaku_plugins` and `claude plugin install insane-search@gptaku-plugins` in the terminal to install it, then tell me to restart Claude Code.

If all else fails, it opens Chrome on your machine and reads the rendered page.

To be fair

If you need to crawl thousands of pages on a schedule, a hosted crawler is the better fit. insane-search won't break into login-only pages or paywalls; it tells you it couldn't read them. It's built for the one public page that stopped your conversation.
