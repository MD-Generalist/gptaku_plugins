403
不是终点。

WebFetch 在公开页面上遇到 403、WAF 或验证码时，insane-search 会依次换用公开 API 与订阅源、浏览器 TLS 指纹、真实 Chrome，直到取回内容。无需 API 密钥；遇到登录墙或付费墙则停下并如实告诉你。

/plugin marketplace add https://github.com/fivetaku/gptaku_plugins.git
/plugin install insane-search@gptaku-plugins
请在终端运行 `claude plugin marketplace add fivetaku/gptaku_plugins` 和 `claude plugin install insane-search@gptaku-plugins` 完成安装，然后提醒我重启 Claude Code。
