Claude Code 缺的
18 件工具

一套安装到 Claude Code 里使用的插件。读取被拦截的网页、带来源核验的研究、组建智能体团队、管理 API 密钥——这些用内置功能很麻烦的事，一条斜杠命令就能完成。

/plugin marketplace add https://github.com/fivetaku/gptaku_plugins.git
请在终端运行 `claude plugin marketplace add fivetaku/gptaku_plugins` 和 `claude plugin install <名称>@gptaku-plugins` 完成安装，然后提醒我重启 Claude Code。

先从这两个开始

insane-search

Claude Code 默认的抓取遇到 403、WAF 或 CAPTCHA 就会放弃。insane-search 从公开 API 和订阅源逐级升级到浏览器 TLS 指纹和真实 Chrome，直到取回公开内容，全程无需 API 密钥。

去看看 →

insane-research

让 AI 做研究，结论里很容易混入来源不明的说法。insane-research 让多个智能体并行检索网络、学术与技术来源，关键论断至少经 2 个来源交叉验证，最终交付带 A–E 来源评级的引用报告。

全部插件

勾选后可以一次复制全部安装命令。

insane-searchClaude Code 抓取网页遇到 403 或 WAF 拦截时，逐级尝试公开路径，直到取回页面内容。
insane-research输入一个问题，多个智能体并行检索网络与学术来源，生成附带内联引用的研究报告。
insane-review用 repomix 打包相关代码，通过已登录的 ChatGPT 网页会话发给 GPT Pro，并取回评审结果。
insane-design抓取网站真实 CSS，把颜色、排版、间距、阴影等令牌提取成 AI 可直接使用的 design.md。
kkirikkiri用一句话描述目标，它只询问尚未确定的事项，然后组建并运行一支 AI 智能体团队。
pumasi适合 3 个以上独立模块的任务：Claude 负责设计接口，多个 Codex CLI 并行实现代码。也能生成图片。
show-me-the-prd无需规划经验，用一句话想法生成 PRD、数据模型、阶段计划和 AI 项目规范 4 份文档。
goaljaby读取 PRD 文件夹，生成 5 份评审文档，经你批准后立即启动 /goal 任务。
skillers-suda四位专家代理先讨论你的想法并进行访谈，再生成可用的 Claude Code 技能。
vibe-sunsang分析你的 Claude Code 对话记录，针对 AI 使用习惯给出辅导，并生成成长报告。
docs-guide按项目中安装的版本实时抓取官方文档来回答库和框架问题，并注明来源。
git-teacher不懂 Git 也能用自然语言完成提交、推送和 PR，并用 Google Drive 类比讲解每一步。
nopal一句话即可组合调用 Gmail、日历、云端硬盘、表格等 9 项 Google Workspace 服务。
sangse根据产品资料生成适用于 Smart Store、Coupang、Kurly 的 10~20 张详情页切图，不编造任何信息。
tikeytaka把散落在各个 .env 中的 API 密钥整合进一个加密保险库，一次更新即可同步到所有项目。
ddiring同时运行多个会话时，每条完成通知都会显示项目文件夹、所在终端应用和最后一条提示。
dd无需粘贴，直接把剪贴板里的长日志或截图交给 Claude Code，完整内容保存在本地文件中。
gaseo把在终端启动的 Claude Code 会话登记到 Paseo，之后可以在应用里继续同一段对话。
